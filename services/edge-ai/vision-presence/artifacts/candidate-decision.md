# HomeMind 비전 모델 후보 결정

결정일: 2026-09-03

## 결정

- 최종 채택 모델: **YOLOX-Nano 416 ONNX**
- YOLOX-Tiny는 비교 결과 보존용이며 런타임 폴백으로 사용하지 않음
- 런타임: ONNX Runtime CPU, Pi 5에서는 XNNPACK 우선 검증
- 학습 클래스: `FIGURE` 한 종류
- 공간 판정: bounding box 하단 중앙점과 카메라별 polygon
- 카메라: `CAM-INDOOR-01`, `CAM-OUTDOOR-01`을 번갈아 2~5 FPS 처리

## PC CPU 결과

공식 COCO 사전학습 가중치를 고정 416×416 ONNX로 변환했다. 입력은 두 카메라가 번갈아 들어오는 상황을 모사했으며 각 조건에서 20회 워밍업 후 200회 측정했다.

| CPU 스레드 | Nano P95 | Tiny P95 | Nano 평균 | Tiny 평균 |
|---:|---:|---:|---:|---:|
| 1 | 24.558 ms | 95.522 ms | 16.418 ms | 69.166 ms |
| 2 | 9.493 ms | 52.873 ms | 8.536 ms | 48.548 ms |
| 4 | 6.450 ms | 30.565 ms | 5.274 ms | 25.153 ms |

| 항목 | Nano | Tiny |
|---|---:|---:|
| 파라미터 | 912,159 | 5,055,855 |
| ONNX 크기 | 3,713,690 bytes | 20,258,878 bytes |
| 4스레드 RSS 증가 | 약 31.9 MB | 약 49.7 MB |

PC 결과는 후보 간 상대 비교이며 Raspberry Pi 5 성능을 의미하지 않는다. 현재 인형이 없으므로 최종 인형 정밀도·재현율도 측정하지 않았다.

## 인형 없는 대체 검출 시험

공식 YOLOX 예제 사진으로 `이미지 읽기 → 416 letterbox → ONNX 추론 → raw YOLOX decode → class별 NMS → bounding box 저장` 경로를 시험했다.

- Nano: 주요 dog 검출 confidence 0.855
- Tiny: 주요 dog 검출 confidence 0.542
- 두 후보 모두 유효한 bounding box 이미지를 생성함

이 값은 모델 선택용 인형 정확도가 아니며 COCO 사전학습 모델과 공개 예제 사진의 파이프라인 작동 여부만 증명한다.

## 실제 인형 확정 후 검증 기준

동일한 독립 테스트 영상으로 두 모델을 비교한다.

- Nano의 `FIGURE` recall 97% 이상
- 안정화 후 zone accuracy 99% 이상
- 30분 정지 인형 시험에서 잘못된 zone 전환 0회
- Pi 5 전체 스택에서 2개 카메라 각각 5 FPS, OOM 0회, 열 스로틀링 0회
- EXAONE 요청 중에도 비전 이벤트 P95 200ms 이하

기준에 미달하면 먼저 촬영 데이터·증강·입력 크기·탐지 임계값을 개선한다. 모델 교체는 별도 설계 변경으로만 진행한다.

## 아직 측정하지 않은 항목

- 실제 인형의 크기·재질·색상별 검출률
- 실제 원룸 모형 조명과 카메라 각도
- Pi 5의 ONNX Runtime/XNNPACK 지연·RAM·온도
- 내부·외부 카메라 드라이버와 동시에 연결했을 때의 프레임 드롭
- 전체 시스템 30분 동시 부하
