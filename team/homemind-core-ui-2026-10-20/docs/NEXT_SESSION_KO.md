## 다음에 수행할 실물 작업

1. Pi5에 Flutter 앱을 설치하고 1024×600 전체화면·터치·종료 버튼을 확인한다.
2. 실제 ESP32/ESP8266 펌웨어에 공식 ID와 MQTT 규격, 중복 명령 방지 ACK를 적용한다.
3. 실제 센서값을 Pi4에 보내 정상·오류·15초 offline 화면을 확인한다.
4. 카메라 인형 인식 모델을 실제 조명·가림·거리 조건에서 조정한다.
5. LED·FND·팬·서보의 별도 전원, 레벨 컨버터와 배선을 부하 상태에서 시험한다.
6. 실물 동선으로 귀가 → 취침 → 야간 침대 이탈 전체 시연을 수행한다.

## 금지사항

- 운영 DB를 삭제하거나 덮어쓰지 않는다.
- 센서 데이터 자동 삭제를 활성화하지 않는다.
- 자동 백업을 임의로 설정하지 않는다.
- 실제 디스크를 채워 저장공간 경고를 시험하지 않는다.
- 검증되지 않은 IPK를 현재 Pi4에 바로 설치하지 않는다.
