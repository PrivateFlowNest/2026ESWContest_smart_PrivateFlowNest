# HomeMind Pi4 Core 0.5.1 변경 요약

## 동작 보완

- ACK가 없을 때 3초 간격으로 같은 `command_id`를 최대 세 번 전송한다.
- 세 번째 시도에도 ACK가 없으면 Task를 `failed`로 끝내고 `ACK_TIMEOUT`을 UI에 전달한다.
- Pi4의 현재 시간이 신뢰 가능한지, 부팅 후 얼마나 지났는지를 snapshot의 `clock`에 포함한다.
- 시간이 신뢰되지 않아도 센서 원본은 삭제하지 않고 부팅 ID와 부팅 후 수신 시간을 함께 저장한다.
- 장치 오프라인 15초 판정과 저장공간 정기검사는 잘못된 벽시계 대신 부팅 후 경과시간을 사용한다.
- 저장공간은 70%에서 경고만 발생하며 자동 삭제는 계속 비활성화되어 있다.

## Flutter UI 보완

- 최근 SQLite 작업 최대 100개를 `기록` 화면에 표시한다.
- Task 실패 원인과 재시도 가능 여부를 표시한다.
- Pi4 시간이 신뢰되지 않으면 작업·시스템 날짜를 `시간 미확인`으로 표시한다.
- 기존 MQTT 자동 재연결, 장치 오프라인, 센서·시스템 상태 화면을 유지한다.

## 재설치 파일

- 파일: `dist-ipk/homemind-core_0.5.1_aarch64.ipk`
- 아키텍처: AArch64
- SHA-256: `b1afb57ea1904b0be4375e13505d27a12b9f694046980f85b3fd79ee02bfa0c0`
- 기존 운영 DB와 설정을 보존하는 업그레이드 구조다.

현재 Pi4에는 장시간 시험을 통과한 동일 실행 파일을 직접 배포한 뒤 재부팅 복구를 확인한다. IPK는 재설치용으로 보관하며 이번 시험 중 운영 DB에 다시 설치하지 않는다.
