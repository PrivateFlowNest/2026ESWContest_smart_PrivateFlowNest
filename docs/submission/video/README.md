- 쓴 촬영분: (2) 창문 열기·닫기, 화장실 냄새 → 환기팬(확대 창), (3) 거실 불·에어컨 켜기, 좀 추운데 → 에어컨 표시등 꺼짐(약 31초 뒤), (4) 모형 전체, 21:50 실기 7인치 카메라 화면

## 화면 UI (실제 앱 코드 녹화)

화면 장면(`ui-*`)의 7인치 화면과 휴대폰 화면은 손으로 그린 그림이 아닙니다. 실제 7인치 UI(`team/homemind-core-ui-2026-10-20/homemind_flutter_test`)와 휴대폰 앱(`team/homemind-application-2026-10-21`) 코드를 `flutter test`의 가상 시계로 1/30초씩 진행하며 한 프레임씩 녹화한 것입니다(`ui/record.js`).

- 7인치 UI는 1280×720(16:9)입니다. 키오스크 틀이 1024×600 배치를 화면 비율에 맞춰 넓히는 실제 코드 그대로입니다. 휴대폰은 세로 390×844(2배, 780×1688)입니다.
- 화면 코드는 그대로 쓰고 데이터만 각본으로 넣습니다. 7인치는 MQTT 대신 각본 데이터 소스를, 휴대폰은 Mobile API 대신 각본 API를 씁니다. 버튼 누름은 손가락 표시와 함께 들어갑니다.
- 시험 엔진 차이 하나만 복사본에서 고칩니다. 휴대폰 머리글은 글꼴 이름이 없어 폰에서는 시스템 글꼴(Roboto)로 나오는데, 시험 엔진은 네모 시험 글꼴로 그립니다. 그래서 복사본에 Roboto를 적습니다(`record.js`의 `PATCHES`). `team/`의 앱은 바꾸지 않습니다.
- EXAONE 대기(실기 15~20초)는 화면 장면에서 줄이고, 그 구간에 "중간 생략"을 표시합니다.
- 결과: `out/ui/<clip>/`(PNG 프레임과 `frames.json`)과 `out/ui/<clip>.mp4`. 화면 장면은 이 프레임을 크게 보여 줍니다. 3D 설명 장면의 디스플레이와 휴대폰에도 같은 녹화를 장면 시각에 맞춰 작게 입힙니다(`scene.js`의 `UI_SYNC`).
- PC에서 재현한 화면이므로 실기 결과가 아닙니다.

## 실행

```bash
npm install                  # three, puppeteer(Chrome), ffmpeg-static
node ui/record.js            # 7인치 UI·휴대폰 화면 녹화 -> out/ui/ (Flutter SDK 필요, FLUTTER=경로로 바꿀 수 있음)
node render.js               # 도식 장면 -> out/<장면>.mp4 (1280x720, 30fps)
node render.js --stills hidden:3,15   # 확인용 정지 화면
node assemble.js             # footage/에 있는 촬영본과 합쳐 out/..._시연동영상.mp4
```

`footage/`의 촬영본은 크기가 커서 git에 넣지 않습니다.

## 실기 촬영 목록 (휴대폰 가로, 720p 이상, 소리 포함)

1. **model-tour**(약 8초): 모형 전체를 천천히 훑습니다. Pi 세 대, 7인치 화면, ESP32·ESP8266, 문·창문·LED·팬이 보이게 찍습니다.
2. **hidden-intent**(약 10초): 마이크 앞에서 "아 좀 덥네"라고 말합니다. 7인치에 "에어컨을 켤까요?"가 뜨면 승인하고, 에어컨 표시등이 켜지는 것까지 찍습니다.
   - EXAONE은 실기에서 한 문장에 15~20초 걸립니다. 기다리는 구간을 잘라 냈다면 화면에 "중간 생략"이라고 표시합니다.
3. **quiet-mode**(약 10초): 노트북으로 회의 음성을 틀어 7인치에 조용 모드 배너가 뜨고 에어컨 표시등이 깜빡이는 장면을 찍습니다. 이어서 "상황이 달라요"를 눌러 해제되는 장면까지 찍습니다.
4. **window-door**(약 10초):
   - "창문 열어 줘" → 창문 모터가 열립니다.
   - "현관문 열어 줘" → 휴대폰에는 승인할 수 없다는 안내가 뜨고, 7인치에서 승인하면 현관문이 열립니다.
5. **partial-hint**(약 6초): "거실 불 켜 줘"라고 말하는 도중에 7인치에 "거실 조명 준비"가 뜨고, 말이 끝나면 조명이 켜지는 장면을 찍습니다.
   - 기기에서 부분 발화 기능을 켜야 찍을 수 있습니다.
